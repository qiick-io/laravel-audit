# Reference schema

The package ships one migration,
`database/migrations/2026_11_24_000000_create_activity_log_table.php`, loaded
unless `audit.migrations.load` is false. It is editable in place until
`1.0.0`, then forward-only and additive. `tests/Feature/ActivityLogSchemaTest.php`
checks it on SQLite, PostgreSQL, MySQL and MariaDB.

externa 1.x keeps its released table and adopts these columns through its own
additive migrations, with `subject_ref` / `causer_ref` named in
`audit.columns` (design §6.2–6.3).

## `activity_log`

| Column | Type | Null | Default | Index | Notes |
| --- | --- | --- | --- | --- | --- |
| `id` | bigint unsigned, auto | no | — | PK | Internal only; never serialised (`Activity::getHidden()`) |
| `public_id` | uuid (v7, RFC 9562) | no | generated by the model | unique | The id resources and exports use |
| `log_name` | string(255) | yes | null | (`log_name`, `created_at`) | Stored trimmed and lower-cased |
| `description` | text | no | — | — | Free text; see the erasure perimeter in the README |
| `event` | string(255) | yes | null | index | Spatie |
| `subject_type` | string(255) | yes | null | `subject` (`subject_type`, `subject_id`) | Morph class (morph map alias when set) |
| `subject_id` | string(64) | yes | null | in `subject` | bigint, UUID and ULID keys, bound as strings |
| `causer_type` | string(255) | yes | null | `causer` (`causer_type`, `causer_id`) | Morph class |
| `causer_id` | string(64) | yes | null | in `causer` | As `subject_id` |
| `organisation_id` | uuid | yes | null | (`organisation_id`, `created_at`) | Tenant perimeter; never taken from `properties` |
| `attribute_changes` | json | yes | null | — | Spatie v5; secret values stored as `[redacted]` |
| `properties` | json | yes | null | — | Reserved keys written by the package (see `docs/public-api.md`) |
| `schema_version` | unsignedSmallInteger | no | `1` | — | `1` current row format, `0` legacy externa row |
| `request_id` | string(128) | yes | null | index | From Laravel's context `request_id` (http-basics accepts up to 128) |
| `anonymised_at` | dateTime | yes | null | — | Set by the anonymiser |
| `created_at` | dateTime | no | — (written in UTC by the code) | index; (`log_name`, `created_at`), (`organisation_id`, `created_at`) | Retention and date filters scan it |
| `updated_at` | dateTime | yes | null | — | |

- No foreign keys: activity morphs never cascade, and rows are anonymised,
  never deleted on erasure.
- No soft deletes. Rows leave only through the retention purge.
- DATETIME, never MySQL `TIMESTAMP` (which ends on 2038-01-19); every value is
  UTC (`app.timezone` must be `UTC`, a boot check).
- Index names are stable: `subject`, `causer`,
  `activity_log_organisation_created_at`, `activity_log_log_name_created_at`,
  plus Laravel's default names for the single-column indexes and the
  `public_id` unique index.
- MySQL / MariaDB index sizes: `subject` and `causer` are (255 + 64) × 4 =
  1,276 bytes, under 3,072.

### Value sets

- `schema_version`: `0`, `1`; a value above `1` is a future additive format,
  and readers fail closed on values they do not know.
- `properties.actor_kind`: `web_session`, `api_key`, `oauth_grant`,
  `public_api`, `unattended` (laravel-access `ActorKind`).
- Security logs (`audit.security_log_names`, default `auth`, `security`,
  `access`, `api-keys`) are kept `audit.security_retention_days` (730); every
  other log `audit.retention_days` (365).
